How to remember it

Normalize = fit everything into one box. Like turning marks into a percentage: 40/50 and 80/100 both become 0.8. Formula: (x − min) / (max − min), so every value lands between 0 and 1.

Standardize = steps from average. z = +2 means "two standard deviations above average", whichever exam or unit it came from. Formula: (x − mean) / std, which puts the average at 0 and makes the spread 1.

What stays the same. All three methods are (x − a) / b. Within a feature, the order of values and the ratios of the gaps between them are kept, and the shape of the distribution does not change. Each feature gets its own a and b, so the balance between features changes.

Why bother? Models that measure distance or use gradients (KNN, k-means, SVM, PCA, neural nets) treat 1 unit in any column as equal. Unscaled, ₹1 counts the same as 1 year. Tree models split on thresholds, so they don't care.

Outliers. Min-max lets one extreme value own the box. Z-score is stretched too, but the outlier stands out at |z| ≈ 3, which is a quick anomaly flag. Robust scaling (median and IQR) ignores it.
