Chapter 1The problem: bigger numbers win the vote

A teacher ranks 8 students by Maths + Sports. Maths is marked out of 100 and Sports out of 10. Nobody decided that Maths should matter more, but it does: Maths marks spread over tens of points, while Sports marks spread over only a few points, so Maths decides almost everything.

Core idea. When you combine columns (add them, measure distance, feed them to a model), the column whose values vary more in raw numbers quietly gets more say. That is the problem scaling fixes.

Chapter 2Normalization: put every column in the same box

Normalization (also called min-max scaling) squeezes each column so its smallest value becomes 0 and its largest becomes 1.

normalized = (x − min) / (max − min)

Read it in two steps. x − min asks "how far above the lowest value is this?" Dividing by max − min (the full range) turns that into a fraction of the range. It works like a percentage, except 0% means "the lowest in the class" rather than "zero marks".

Worked example, Maths in Lab 1: min is 60 and max is 95. Aman scored 80, so (80 − 60) / (95 − 60) = 20 / 35 = 0.57. He sits 57% of the way up the Maths range.

Remember it as: "Where does this value sit between the lowest and the highest?" The answer is always between 0 and 1.

Chapter 3Standardization: count steps from the average

Standardization (also called the z-score) asks a different question: how unusual is this value? It does two things.

First it subtracts the mean (the average), so the average becomes 0. Values above average become positive and values below become negative. Then it divides by the standard deviation, which is the typical distance of values from the average. That makes the answer a count of "steps", where one step is a typical gap for that column.

z = (x − mean) / standard deviation

Worked example, Sports in Lab 1: the mean is about 5.6 and the standard deviation is about 2.5. Aman scored 10, so (10 − 5.6) / 2.5 ≈ +1.75. He is 1.75 steps above the average, which is very good for Sports. Riya's Maths 90 is (90 − 77.5) / 11.5 ≈ +1.09: good, but less unusual.

Remember it as: "How many typical steps above or below average?" There is no fixed range; most values land between −2 and +2, and beyond ±3 is rare.

Chapter 4Outliers: where the two methods behave differently

Load Salaries + one CEO in Lab 2. One person earns ₹10,00,000 while everyone else earns ₹32,000 to ₹1,05,000.

Min-max gives the CEO the value 1, because they are the max. Everyone else gets crushed into 0 to 0.07, so the differences between normal people almost disappear. Min-max trusts the min and the max, and an outlier is the max.

Z-score is stretched too, because the outlier pulls the mean up and makes the standard deviation larger. But the outlier gets a z of about +3.5, so it is clearly flagged as unusual. That is why z-scores are a classic first anomaly detector. The flagged row in the table turns yellow.

Robust scaling uses the median (the middle value) instead of the mean, and the IQR (the spread of the middle 50% of values) instead of the standard deviation. One extreme value barely moves either of them, so normal people keep their spread.

robust = (x − median) / IQR

Chapter 5Why ML cares: distance is a sum of gaps

Many models judge how similar two rows are by distance:

distance = √( gap_in_age² + gap_in_salary² )

This is exactly the Maths + Sports problem again. Each column adds its gap, and a column measured in big numbers (salary, in thousands) overpowers one measured in small numbers (age, in tens). Pick two people below and look at how much of the distance each feature supplies.

Min-maxWhere between lowest and highest?0 to 1You need a fixed range (image pixels, some neural net inputs) and there are no big outliersOne outlier crushes everyone else
Z-scoreHow many typical steps from average?Centred on 0, mostly −3 to +3The default for most models; flagging unusual valuesThe outlier still stretches mean and std
RobustSteps from the middle, ignoring extremesCentred on 0Data with outliers you must keepSlightly less familiar to explain

When not to bother. Tree models (decision trees, random forest, XGBoost) never add columns together. They ask one question about one column at a time, such as "is salary > 50,000?". Scaling doesn't change the order of values, so the same split works either way.

The train/test rule. Calculate min, max, mean and standard deviation from the training data only, then apply those same numbers to the test data and to new data in production. If you calculate them on all the data first, information from the test set leaks into training and your evaluation looks better than reality.

What scaling never changes. The order of values within a column, and the shape of their pattern. Scaling is always (x − a) / b, which only slides and stretches the ruler. What it changes is the balance between columns.

Chapter 7Test yourself

Say your answer out loud first, then open it.

1. In one sentence, what problem does scaling solve?

When columns are combined, columns with bigger raw numbers quietly get more weight; scaling puts every column on a comparable ruler so each gets a fair say.

2. A column has min 20 and max 70. What is 45 after min-max scaling?

(45 − 20) / (70 − 20) = 25 / 50 = 0.5. It sits exactly halfway between lowest and highest.

3. A value has z = −2. What does that mean?

It is two standard deviations (two typical steps) below the average. That is unusually low, but not extreme.

4. Your data has a few huge outliers that are real and must stay. Which scaler, and why?

Robust scaling. Median and IQR barely move because of a few extreme values, so the normal rows keep their spread. Min-max would crush them.

5. Why don't random forests need scaling?

Each split compares one column with a threshold. Scaling keeps the order of values, so the same split separates the same rows. Columns are never added together, so no column can overpower another.

6. You computed the mean and std on the whole dataset, then split into train and test. What's wrong?

Data leakage. The test set influenced the scaling numbers, so the model indirectly saw test data. Fit the scaler on train only, then reuse it for test and production.

7. In production, a new value is bigger than the training max. What does min-max give?

A value above 1. Models that assume inputs stay in 0 to 1 may behave strangely, which is one more reason min-max is fragile.
