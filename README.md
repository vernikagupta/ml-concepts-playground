# ML Concepts Playground

Interactive pages for learning machine-learning concepts by changing the data and watching what happens. Plain HTML and JavaScript, no build step.

**Live site:** https://vernikagupta.github.io/ml-concepts-playground/

## Feature scaling

| Page | What it is |
|---|---|
| [Workbook](feature-scaling/workbook.html) | Normalization, standardization and robust scaling, chapter by chapter, with three live labs and a self-test |
| [Lab](feature-scaling/lab.html) | Watch a dataset move under each scaling method, with and without an outlier |

To run locally, open any `.html` file in a browser.
